# Cybersecurity Fundamentals Lab

This repository documents my hands-on learning journey in cybersecurity, focusing on core technical concepts, practical labs, and security analysis.

The purpose of this project is to build a strong foundation in cybersecurity through structured, real-world style exercises and clear documentation.

## About This Project
This repository showcases my hands-on cybersecurity learning through practical labs focused on networking, incident analysis, log review, and security monitoring. Each lab simulates real-world scenarios and follows a structured documentation approach.

## Topics Covered
- Cybersecurity fundamentals
- System and endpoint security
- Networking basics (TCP/IP, ports, protocols)
- Linux and Windows security concepts
- Log analysis and basic incident investigation
- Security tools and command-line usage

## Lab Structure
Each lab includes:
- Objective
- Tools used
- Steps performed
- Observations
- Key security takeaways

## Tools & Platforms
- Linux (Ubuntu)
- Windows
- Command Line (Bash, PowerShell basics)
- TryHackMe-style labs
- Networking and security utilities

## Current Focus
- Understanding how systems are attacked and defended
- Building practical security thinking
- Developing documentation and analysis skills

This repository will be continuously updated as I progress through my cybersecurity learning path.
