# Lab 02 – Incident Analysis (Mini Lab)

## Objective
Understand the basic incident analysis process by identifying indicators, assessing impact, and documenting findings in a structured manner.

## Scenario
A user reports suspicious activity on their system, including unexpected pop-ups and slow performance.

## Steps Performed
- Identified possible indicators of compromise (IOCs)
- Considered malware or adware as potential causes
- Assessed basic impact and risk
- Documented findings clearly

## Tools Used
- Manual analysis
- System observation
- Incident response thinking

## Findings
- Behavior suggests possible adware or unwanted software
- No evidence of data exfiltration
- System requires monitoring and cleanup

## Key Takeaways
- Documentation is critical in incident handling
- Early detection reduces impact
- Structured thinking is essential for SOC roles
